# かね将プロジェクト 開発ルール (Project Rules)

## アーキテクチャの厳格な分離 (Strict Architectural Separation)

このプロジェクトは、2つの異なる技術スタックで構成されています。将来のスレッドで開発を行う全てのエージェントは、以下のルールを**絶対に**遵守してください。

1. **かね将ポータル (社内管理用) - ルートディレクトリ直下**
   - **技術スタック**: Vanilla HTML, CSS, JavaScript (Reactやビルドツールは一切使用しない)
   - **ルール**: ポータルの既存ファイル（`daily_sakes.js`、`index.html`など）を改修する際、絶対にReactコンポーネントを導入したり、書き換えたりしないでください。現在のシンプルな構成を維持すること。

2. **お客様向け公式Webページ (公開用) - `public_web/` フォルダ内**
   - **技術スタック**: Vite + React + Vanilla CSS
   - **ルール**: お客様向けのページ開発は、全てこの `public_web/` フォルダ内に限定して行います。この中でのみReactを使用します。

このルールはプロジェクトの根幹に関わるため、エージェントは全ての機能開発・提案においてこの制約を最優先で守る必要があります。
